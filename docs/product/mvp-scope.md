# MVP scope

The MVP supports the full academic operating loop: tenant and school onboarding; campuses and academic sessions; classes, sections and subjects; staff and teacher assignments; students, guardians, enrollment and admissions; timetable; attendance; fees and payments; exams, marks, results and report cards; communication; role dashboards and reports; and academic rollover.

Phase 0 contains only the foundation. Later phases add those workflows in dependency order. HR/payroll, library, transport, hostel, inventory, native apps, and AI features are deferred. The PreSkool template contains examples of many of these, but its menu is a visual reference rather than a feature commitment.
