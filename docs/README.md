# Documentation

- `product/` records the MVP and deferred scope.
- `architecture/` records system structure and security boundaries.
- `decisions/` records accepted architecture decisions.
- `development/` explains local setup, testing, and coding standards.
- `superpowers/` contains the Phase 0 design and implementation plan.

Documentation changes alongside implementation. A feature is incomplete when its relevant design, API, or operational notes are stale.
